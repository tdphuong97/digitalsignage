# Bắt đầu nhanh

**Ai làm:** người phụ trách nội dung trên TV · **Mất khoảng:** 2 phút

{% hint style="info" %}
**Trước khi bắt đầu:** phần mềm đã được cài và đã nhập mã API. Nếu chưa, xem [Cài đặt](cai-dat.md).
{% endhint %}

{% stepper %}
{% step %}
### Mở phần mềm

Bấm đúp biểu tượng **Signage Viên Ba** ngoài màn hình. Dưới **TV 1** và **TV 2** hiện số nội dung mỗi TV đang chiếu.
{% endstep %}

{% step %}
### Chọn TV

Bấm **TV 1** hoặc **TV 2**. Khung TV được chọn có viền xanh, và danh sách bên trái đổi thành **Đang chiếu trên TV 1** (hoặc **TV 2**).
{% endstep %}

{% step %}
### Thêm ảnh hoặc video

Kéo file hoặc cả thư mục từ File Explorer thả vào cửa sổ, hoặc bấm **Chọn file…**. File hiện ở khung bên phải với trạng thái **Chờ**.
{% endstep %}

{% step %}
### Đưa lên TV

Bấm **Đưa lên TV 1** (hoặc **Đưa lên TV 2**). Video được nén trước, rồi từng file được tải lên. Xong, mỗi dòng hiện chữ xanh **Đã đưa lên TV 1**.
{% endstep %}

{% step %}
### Kiểm tra

Danh sách bên trái có thêm file mới. TV chiếu nội dung mới khi hết vòng chiếu hiện tại.
{% endstep %}
{% endstepper %}
